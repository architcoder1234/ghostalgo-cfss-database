# 👻 GhostAlgo CFSS 2023 Car Database

A public, read-only community catalogue for Car For Sale Simulator 2023, with a private GhostAlgo admin panel powered by Supabase.

## Features

- Public car search and category filters
- Click a car for full details
- Buy/sell prices and notes
- Supabase shared database
- Supabase image storage
- GhostAlgo email/password admin login
- Add, edit and delete cars
- Upload/replace car images
- Public visitors have no write access
- GitHub Pages compatible

See `SUPABASE_SETUP.md` before publishing.
